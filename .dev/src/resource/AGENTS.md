# .dev/src/resource — JS source tree

## OVERVIEW

Plain-LuCI `E()` DOM modules (no React/Vue) that terser minifies in place into `htdocs/luci-static/resources/`; the only hand-edited frontend code in the repo.

## STRUCTURE

```
src/resource/
├── view/aurora/studio.js       # Theme Studio: color editor, layout, branding, toolbar, fonts
├── view/aurora/marketplace.js  # Marketplace: store cards, share modal, my-shares
├── utils/asset-upload.js       # Dropzone/upload widget
├── utils/color.global.js       # VENDORED colorjs.io, global `Color`, .license sidecar
├── utils/tokens.global.js      # VENDORED token engine, global `AuroraTokens`, GENERATED
├── utils/hub-api.js            # rpc.declare wrappers for hub_* + list cache
├── utils/theme-preview.js      # Live preview helpers
├── utils/feed-check.js         # Feed/update check
└── aurora/presets.json         # GENERATED preset data (gen-presets.mjs)
```

## CONVENTIONS

- **LuCI module format:** every file starts with `"require X"` directives (LuCI's loader resolves them over HTTP, so never merge files) and ends with a top-level `return view.extend({...})`.
- **Versioned self-fetches:** `__ASSET_HASH(path)__` is replaced at build (sha256 first 8 hex); `TOKENS_ENGINE_VERSION` is stamped by `sync-tokens.mjs`. Never add a self-built fetch URL without one of these.
- **Marketplace trust boundary:** ALL hub-sourced text (name, author, palette hex, toolbar URLs) is untrusted. Render only via `E()` safe children / `document.createTextNode`; sanitize palette hex before `color-mix()`.
- **Vendored files are read-only:** `color.global.js`, `tokens.global.js`, `aurora/presets.json` are regenerated by pipelines, never hand-edited.

## ANTI-PATTERNS

- **Never hand-edit `htdocs/`** — this tree is the source of truth; build-js.mjs is the sole writer of minified artifacts.
- **Never use `innerHTML` for hub-sourced text** — untrusted server content; `E()` safe children / `createTextNode` only.
- **Never edit vendored `tokens.global.js` / `color.global.js` / `aurora/presets.json`** — regenerate via `pnpm sync-tokens` / `pnpm gen-presets`.
- **Never merge module files** — LuCI's loader resolves `"require"` over HTTP; merged files break it.
- **Never enable `mangle.toplevel`/`compress.toplevel`** in terser — deletes `var Color`/`var AuroraTokens`, output goes empty while terser still reports success.
