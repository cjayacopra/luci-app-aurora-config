# root/ — AGENTS.md

## OVERVIEW

Installed-as-is OpenWrt filesystem overlay for luci-app-aurora-config: the POSIX-sh rpcd backend, first-boot UCI seeding, preset templates, and ACL/menu wiring. No build step touches these files; the SDK installs them verbatim.

## STRUCTURE

```
root/
├── usr/libexec/rpcd/luci.aurora        # Backend: 3929 lines POSIX sh + jshn
├── etc/uci-defaults/80_aurora          # First-boot: SCHEMA_VERSION=7, migration + template seed
├── etc/uci-defaults/81_aurora-fonts    # Font cache migration
├── usr/share/aurora/*.template         # 6 UCI presets (default, shiranekowrt, sage-green, amber-sand, monochrome, sky-blue)
├── usr/share/aurora/color-tokens.conf  # GENERATED vendored ordered token key list
├── usr/share/aurora/font-presets.conf  # GENERATED font registry (v2|generated-by-gen-font-presets|do-not-edit)
├── usr/share/aurora/feed/              # eamonxg.pem/.pub theme-store signing keys
├── usr/share/luci/menu.d/luci-app-aurora.json   # Menu: studio + marketplace
├── usr/share/rpcd/acl.d/luci-app-aurora.json    # ACL; MUST match rpcd method table
└── etc/sysupgrade.conf.d/aurora-device # Preserves /etc/aurora/device.{key,hash} across sysupgrade
```

## WHERE TO LOOK

| Task | Location |
|------|----------|
| RPC methods | `luci.aurora` — dispatch is `case "$1" in "list")` at ~line 2937, `"call")` at ~3007 |
| Upload gate | `luci.aurora` `receive_upload()` (~line 58): MAX_UPLOAD=8388608, woff2 magic check, image extension allowlist |
| Schema migration | `80_aurora` `migrate_color_schema()` / `reseed_colors_from_template()` |
| Preset validation | `luci.aurora` — PRESET_EXPECTED_COUNT derives from color-tokens.conf (count × 2); count mismatch rejects the preset |
| Font stacks | `font-presets.conf` field 7; device reverse-map fails if not copied verbatim |

## CONVENTIONS

- **Backend is SECURITY-CRITICAL.** Validate every input with `case`/`grep -E` only, never `eval`. Quote all variables. Treat hub-sourced content as untrusted. Guard against embedded-newline UCI injection.
- **ACL must mirror the method table.** `acl.d/luci-app-aurora.json` and the `case` dispatch in `luci.aurora` must agree; tests enforce this.
- **Any token change bumps SCHEMA_VERSION** in `80_aurora` and adds a comment; stale UCI keys become dangling overrides otherwise.
- **A preset is a whole look**: 62 colour options plus the structural block (`struct_*`, toolbar). Colour block is GENERATED by `gen-presets.mjs`; layout/typography block is hand-authored.
- **Never hand-edit generated files**: `color-tokens.conf`, `font-presets.conf`, template colour blocks. Regenerate via `pnpm sync-tokens` / `pnpm gen-presets` / `pnpm gen-font-presets`.
- **ACL group name `luci-app-aurora` ≠ package name** `luci-app-aurora-config`.

## ANTI-PATTERNS

- **Never use `eval`** in rpcd — validation is `case`/`grep -E` only; no embedded-newline UCI injection.
- **Never trust hub payloads** — same receive_upload gate applies to hub-sourced font bytes as to local uploads.
- **Never retype a font stack** — copy verbatim from `font-presets.conf` field 7, or the device reverse-map fails silently.
- **Never hand-edit `color-tokens.conf` / `font-presets.conf` / template colour blocks** — drift is caught by token-sync-check + tests.
- **Never skip the SCHEMA_VERSION bump** on token changes — stale UCI keys silently override new defaults.
